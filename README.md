## MKCloud 卖的是什么：先搞清产品再谈价格

MKCloud（mkcloud.net）不是普通的海外 VPS 商家，它卖的是**云服务器/独立服务器 + 跨境专线网络**的组合：服务器本身在国内入口侧，跨境段走 IPLC、IEPL 或 IXP 资源，出口给到你一个独立的海外 BGP 出口 IP。官网给的核心卖点是端内延迟——广港 IEPL 1~2ms、沪港 21ms、沪日 25~28ms、沪美 124~134ms，这些是物理路径决定的，普通公网 VPS 做不到。

也正因为这个定位，它的套餐和 Linode、Vultr 这类机器不是一回事：

- 每台配 **2 个独享 IPv4**（入口一个、出口一个），出口 IP 用于对外访问；
- 出口只做**向外访问，不接收入站**，不能当建站主机用；
- 需要中国身份信息**实名**，明确禁止机场、回国等违规用途，违规清退不退款；
- 部分产品有**省级白名单**限制，只允许一个省份的 IP 连入（后续可改）。

一句话：这是给跨境电商、独立站、需要稳定跨境链路的企业业务用的东西，不是翻墙工具。

## 两种计费模式：流量计费和独享带宽

MKCloud 的每条线路都分两种买法，这也是很多人比价比不明白的原因。

**流量计费（共享带宽）**：按月流量额度卖，比如 1TB、2TB、4TB。给的是峰值带宽（200M～5G 不等），共享网络不保证持续跑满。计量按**上行+下行双向统计**，额度用完会停机，可以自助购买流量重置，或者提工单补差价升级。适合用量不固定、有突发上传的业务，比如日常上货、订单同步。

**带宽计费（独享带宽）**：按配置速率卖，5M 起步，不限流量。独享带宽 5M 和共享峰值 200M 不是一回事——前者保证你 24 小时都能以 5Mbps 的持续速率传输，后者只保证峰值能摸到 200M。文件大、上传时间长、要求传输稳定的场景，独享反而更划算。官方知识库里给的对比很直接：沪港共享入门 288 元/月（200Mbps 峰值、1024GB 月流量），独享入门 388 元/月（5Mbps、不限流量），差 100 块买的是"随时能跑满 5M"。

## 同一个 1TB，价格为什么差这么多

把六条线的入门档放在一起看，从 158 到 428 差了近两倍，差价主要在两处：

**一是入口。** 两条 IXP 线便宜，是因为入口走云厂优化通道，前提是你手上已经有腾讯云、阿里云这类国内云网络作为前置，专线本身只解决"从云厂到海外出口"这一段。如果你没有云前置，那 158 元的深港 IXP 对你来说不完整，还得算上一台云服务器的钱。IPLC/IEPL 直连款自带入口，开箱就能连，这部分成本就体现在价格里了。

**二是路径。** 广港 IEPL 走的是深港/广港方向的专线资源，1~2ms 的端内延迟是全部线路里最好的；沪美方向物理距离摆在那里，124~134ms，直连和 IXP 在这个方向上延迟一样，所以才敢把 IXP 做成 266 元——美区方向省钱的逻辑比香港方向更顺。

还有一个不太直观的点：同样的钱，在不同线路上买到的 CPU、内存、硬盘是一样的（入门都是 1核2GB/20GB 或 2核4GB/40GB 的规格），你真正付的差价全是网络成本。所以选 mkcloud 套餐的第一步不是比配置，是确认你的业务到底走哪个出口、人在哪个省份、有没有云前置。

## 下单前必须知道的几条规则

这些是商店页和知识库里白纸黑字写的限制，买之前过一遍，能省掉很多售后麻烦：

3. **地域不可更换**：服务开通后不支持更换到其他地域的产品，买广港还是沪美，下单前就要定好。
4. **退款门槛高**：仅支持质量问题退款，且需要你提供准确具体的延迟、速度数据作为证据，不是"不想要了就能退"。

6. **无默认 SLA**：需要可用性赔付条款的，要先谈定制合同，不要默认套餐里含 SLA。

## 常见问题

**Q：mkcloud 是机场吗？** 不是。它卖的是云服务器/独立服务器加跨境专线，需要实名，官方明确禁止机场类用途。搜它的测评文章也会看到同样的提醒：这是给正规企业业务用的。

**Q：为什么搜不到月付几十块的套餐？** IPLC/IEPL 专线资源本身贵，直连款入门就是 198～428 元/月这个区间。全站最便宜的 158 元深港 IXP 也需要云前置搭配，单独那一百多块买不来完整链路。

**Q：出口 IP 能建站吗？** 不能。出口只用于向外访问，不接收入站，它和能对外提供网站服务的云主机不是一回事。

**Q：买错了能换线路吗？** 不能。开通后不支持更换到其他地域，退款又只认质量问题，所以下单前对着上面的表格把线路和档位确认清楚再付款。
